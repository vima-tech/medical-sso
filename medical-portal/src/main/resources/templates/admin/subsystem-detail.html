错误

接入方式

决定对接文档给出哪一套说明。改动接入方式后回调地址会一并调整。

系统角色

除了「能否进入」之外，业务系统可以在这里登记自己的粗粒度角色，随 Token 下发供其内部判断。 access 由平台使用，不能删除。

  • access 能否进入本系统，由平台维护
  • outpatient-doctor

Client Secret

重新生成后旧 Secret 立即失效，该业务系统必须同步更新配置，否则会登录失败。仅在泄露或遗失时使用。

停用与删除

停用后该系统立即无法登录，配置保留，可随时恢复。删除会一并移除它的角色，且要求先在授权中心收回全部人员权限。
